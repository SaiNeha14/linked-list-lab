# Linked List Lab

An interactive educational website for learning singly linked lists through visual feedback.

## What it includes

- Append, prepend, insert, delete, search, reverse, and reset operations
- Live node and pointer visualization
- Step-by-step algorithm trace
- Time and space complexity explanations
- Responsive desktop and mobile layout

## Run locally

`pnpm install`

`PORT=5173 BASE_PATH=/ pnpm --filter @workspace/linked-list-lab run dev`

Then open the local Vite URL shown in the terminal.

## Project location

The app lives in `artifacts/linked-list-lab`.
